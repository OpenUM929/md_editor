## 2. 엔드포인트

### `{METHOD} /api/{resource}`

**설명:** (예: 단건 사용자 조회)

**요청 헤더:**

| 헤더 | 값 | 필수 |
|------|----|------|
| Content-Type | application/json | Y |
| Authorization | Bearer {token} | Y |

**요청 본문:**

```json
{
  "key": "value"
}
```

**응답 본문:**

```json
{
  "success": true,
  "data": {}
}
```

**응답 코드:**

| 코드 | 설명 |
|------|------|
| 200 | 성공 |
| 400 | 잘못된 요청 |
| 401 | 인증 실패 |
| 500 | 서버 오류 |

## 4. 에러 코드

| 코드 | HTTP 상태 | 메시지 | 설명 |
|------|----------|--------|------|
| (예: USER_NOT_FOUND) | 404 | 사용자를 찾을 수 없음 | (예: 잘못된 id) |
| (예: INVALID_TOKEN) | 401 | 토큰이 유효하지 않음 | (예: 만료) |
