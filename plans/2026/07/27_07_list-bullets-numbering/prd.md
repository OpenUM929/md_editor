## 1. 배경

### 1.1 문제 정의

md_editor는 공공기관 보고서(개조식 A4 문서)를 작성해 DOCX/HWPX로 내보내는 것이 핵심 용도다. 이 영역의 사용자는 **한글(HWP)의 "글머리표 및 문단 번호"**, **Word의 "다단계 목록"** 을 기준으로 목록 기능을 인식한다.

그러나 현재 md_editor의 목록 기능은 **Markdown 수준의 최소 구현**에 머물러 있다. 사용자가 "1. → 가. → 1) → (가)" 같은 관공서 표준 번호 체계를 만들 수 없고, 마커를 고를 수도, 번호를 이어가거나 다시 시작할 수도, 들여쓰기를 조절할 수도 없다. 즉 **기능적으로 한글·워드와 닮은 점이 거의 없다.**

### 1.2 현재 구현 실측

| 영역 | 현재 상태 | 근거 |
|------|-----------|------|
| 툴바 | `Bullet List` / `Ordered List` / `Task List` **토글 버튼 3개가 전부**. 마커 선택 UI 없음 | `src/components/editor/editor-toolbar.tsx:453-462` |
| 편집기 스키마 | Tiptap `StarterKit` 기본 `bulletList`/`orderedList`/`listItem` + `TaskList`/`TaskItem`. **커스텀 속성 없음** | `src/components/editor/tiptap-editor.tsx:150-158` |
| 부가 로직 | 바로 위 동일 타입 리스트에 합류(번호 이어짐), 번호 붙은 heading 아래 `start` 지정. **이것이 유일한 번호 관련 기능** | `src/lib/list-continue.ts` (88줄) |
| 수준(level) 변경 | Tiptap `ListItem` 기본 단축키로 `Tab`/`Shift+Tab` 동작(sink/lift). 단 **수준별 마커 구분이 없어 시각적으로 무의미** | `node_modules/@tiptap/extension-list/dist/index.js:513-514` |

| 저장 형식 | `.md` 순정. 문서 옵션은 프론트매터에 저장(`reportTheme`, `headingNumbering`, `pageMode`) | `src/lib/markdown.ts`, `src/components/tab/doc-tab-content.tsx:55-66` |

## 3. 목표 / 비목표

### 3.1 목표

1. 사용자가 **수준별 마커 서식**을 선택해 관공서 표준 번호 체계(`1. → 가. → 1) → (가)`)를 구성할 수 있다.
2. 번호를 **시작값 지정 / 이어가기 / 1부터 다시 시작** 으로 제어할 수 있다.
3. **들여쓰기(마커 위치·텍스트 위치)** 를 문서 단위로 조절할 수 있다.
4. 선택한 서식이 **편집화면 = 인쇄 = PDF = DOCX = HWPX** 에서 동일하게 보인다.
5. 서식 정보가 `.md` 파일에 보존되어 **다시 열었을 때 그대로 복원**된다.
6. `.md` 파일은 **외부 마크다운 도구에서도 읽히는 상태**를 유지한다(HTML 블록 범벅 금지).

### 3.2 비목표 (이번 제품 범위 밖)

- 그림 글머리표(이미지 불릿)
- 목록 스타일 프리셋의 전역 라이브러리·공유 기능
- 표 안 목록의 독립 서식 체계
- 목록 항목 간 드래그 재정렬

## 5. 기능 요구사항

우선순위: **P0** = 1차 릴리스 필수, **P1** = 1차 포함, **P2** = 2차 이후.

### FR-1. 마커 서식 갤러리 (P0)

- 툴바의 글머리표/문단 번호 버튼을 **분할 버튼(토글 + 드롭다운)** 으로 바꾼다.
- 드롭다운에는 아래 서식이 **실제 마커 모양 미리보기**와 함께 나열된다.

**문단 번호 서식(ordered)**

| ID | 표시 | 예 |
|----|------|-----|
| `decimal` | 1. 2. 3. | 기본 |
| `decimalParen` | 1) 2) 3) | |
| `paren` | (1) (2) (3) | |
| `circled` | ① ② ③ | 20까지, 이후 순환 |
| `hangulSyllable` | 가. 나. 다. | |
| `hangulParen` | 가) 나) 다) | |
| `hangulConsonant` | ㄱ. ㄴ. ㄷ. | |
| `upperAlpha` | A. B. C. | |
| `lowerAlpha` | a) b) c) | |
| `upperRoman` | I. II. III. | |
| `lowerRoman` | i. ii. iii. | |
| `hanja` | 一. 二. 三. | |

**글머리표 서식(bullet)**

| ID | 표시 |
|----|------|
| `disc` | ● |
| `circle` | ○ |
| `square` | ■ |
| `hollowSquare` | □ |
| `diamond` | ◆ |
| `dash` | – |
| `middot` | · |
| `check` | ✓ |
| `star` | ※ |
| `triangle` | ▶ |

- **수용 기준**: 갤러리에서 서식을 고르면 커서가 있는 목록의 마커가 즉시 바뀌고, 편집화면·인쇄 미리보기·PDF에서 동일하게 보인다.

### FR-2. 다단계 목록 — 수준별 서식 (P0)

- 문서마다 **수준 1~4의 마커 서식을 미리 정의**한다(문서 목록 스타일 프로필, FR-5).
- 기본 프로필은 관공서 관행에 맞춘다.
  - 문단 번호: `1.` → `가.` → `1)` → `(가)`
  - 글머리표: `□` → `○` → `–` → `·`
- 수준 5 이상은 4수준 서식을 반복한다.
- **수용 기준**: 목록에서 Tab을 눌러 수준을 내리면 마커가 해당 수준 서식으로 자동 변경된다.

### FR-3. 수준 올리기/내리기 (P1)

- `Tab` / `Shift+Tab` 유지(이미 동작)하고, **툴바에 "수준 내리기 / 수준 올리기" 버튼**을 추가해 발견 가능성을 확보한다.
- **수용 기준**: 버튼과 단축키의 결과가 동일하며, 수준 변경 시 마커가 FR-2에 따라 갱신된다.

### FR-4. 번호 제어 (P0)

문단 번호 드롭다운 하단에 다음 항목을 둔다.

| 항목 | 동작 |
|------|------|
| 1부터 다시 시작 | 현재 목록의 `start`를 1로 설정 |
| 이전 목록에 이어서 계속 | 문서 앞쪽에서 같은 수준의 마지막 번호를 찾아 `start` 계산 |
| 시작 번호 지정… | 숫자 입력(1~999) |

- **수용 기준**: 중간에 문단·표가 끼어 있어도 "이어서 계속"이 정확한 번호를 산출한다. 지정한 시작 번호가 저장·재열람 후에도 유지된다.

### FR-5. 문서 목록 스타일 프로필 (P0)

- 문서 전체에 적용되는 목록 서식을 프론트매터 `listStyle` 에 저장한다.
- 툴바에 **"목록 서식…" 설정 패널**을 두어 수준별 마커와 들여쓰기를 한 화면에서 지정한다.

```yaml
---
listStyle:
  ordered: [decimal, hangulSyllable, decimalParen, paren]
  bullet:  [hollowSquare, circle, dash, middot]
  indent:
    step: 20      # pt, 수준당 좌여백 증가량
    hanging: 18   # pt, 마커 → 본문 간격(내어쓰기)
---
```

- 값이 없으면 기본 프로필을 사용하고, 프론트매터에 `listStyle` 키를 쓰지 않는다(기존 문서 무손실).
- **수용 기준**: 기존 문서를 열고 저장해도 프론트매터에 불필요한 키가 추가되지 않는다.

### FR-6. 목록별 서식 오버라이드 (P1)

- 한 문서 안에서 특정 목록만 다른 마커를 쓸 수 있어야 한다(예: 부록만 `①`).
- `.md` 에는 목록 바로 앞에 **디렉티브 주석**으로 기록한다. 목록 본문은 표준 마크다운을 유지한다.

```md
<!-- list: marker=circled start=3 -->
3. 항목 셋
4. 항목 넷
```

- **수용 기준**: 오버라이드된 목록이 왕복(열기→저장→열기) 후에도 동일하게 유지되고, 오버라이드가 없는 목록은 `.md` 에 주석이 생기지 않는다.

### FR-7. 들여쓰기·간격 (P0)

- 프로필의 `indent.step` / `indent.hanging` 값으로 수준별 마커 위치와 본문 들여쓰기를 계산한다.
- 마커 좌여백 = `step × (수준-1)`, 본문 들여쓰기 = 마커 좌여백 + `hanging`.
- **수용 기준**: 값 변경이 편집화면·인쇄·PDF·DOCX·HWPX에 동일 비율로 반영된다.

### FR-8. 저장/왕복 보존 (P0)

- 프로필은 프론트매터, 목록별 오버라이드는 디렉티브 주석, 시작 번호는 마크다운 고유 표기(`3.`)로 저장한다.
- Tiptap이 `<template data-frontmatter>` 를 떨궈내는 기존 제약 때문에 저장 경계에서 `injectFrontmatter` 로 재부착하는 규칙을 그대로 따른다.
- **수용 기준**: 열기→편집→저장→다시 열기 후 목록 서식이 100% 동일. 탭 전환(언마운트) 후에도 유실 없음.

### FR-9. 내보내기 반영 (P0)

| 대상 | 요구 |
|------|------|
| 인쇄 / PDF | 편집화면과 동일한 마커·들여쓰기 |
| DOCX | 프로필로부터 넘버링 정의를 **동적 생성**. 한글 서식은 `GANADA`(가나다)·`CHOSUNG`(ㄱㄴㄷ)·`DECIMAL_ENCLOSED_CIRCLE`(①) 매핑 사용 |
| HWPX | 글머리표는 마커 문자 그대로 전달, 문단 번호는 서식별 매핑. 수준 지원을 3단 → 4단으로 확대 |

- **수용 기준**: 내보낸 DOCX를 Word에서, HWPX를 한글에서 열었을 때 마커·수준·들여쓰기가 화면과 일치한다.

### FR-10. 계층 결합 번호 (P2)

- `1.1`, `1.1.1` 형태의 결합 번호 서식. 제목 번호(`heading-numbering.ts`)와 동일한 시각 체계.

### FR-11. 사용자 정의 번호 서식 (P2)

- 접두/접미 문자 직접 입력(예: `제 %1 장`, `[%1]`).

### FR-12. 개요 번호 연동 (P2)

- 제목 자동 번호와 목록 번호를 하나의 다단계 체계로 연결(Word의 제목 스타일 연결 상당).

### FR-13. 마커 글자 모양 (P2)

- 마커 색상·굵기를 본문과 별도로 지정.

## 8. UX 설계

```
[ ≡ ▾ ]  [ 1≡ ▾ ]  [ ☑ ]   [ ⇥ ]  [ ⇤ ]     ← 툴바 목록 그룹
  │        │                  수준 내리기/올리기
  │        └─ 문단 번호 드롭다운
  │             ┌───────────────────────────┐
  │             │ 1.   1)   (1)   ①         │  ← 서식 갤러리(미리보기)
  │             │ 가.  가)  ㄱ.   A.        │
  │             │ a)   I.   i.    一.       │
  │             ├───────────────────────────┤
  │             │ 1부터 다시 시작            │
  │             │ 이전 목록에 이어서 계속     │
  │             │ 시작 번호 지정…            │
  │             ├───────────────────────────┤
  │             │ 목록 서식…                 │  ← 프로필 설정 패널
  │             └───────────────────────────┘
  └─ 글머리표 드롭다운: ● ○ ■ □ ◆ – · ✓ ※ ▶ + [목록 서식…]
```

- 버튼 본체 클릭 = 기존 토글(합류 로직 `list-continue.ts` 유지), 화살표 클릭 = 갤러리.
- "목록 서식…" 패널: 수준 1~4 각각의 마커 선택 + `step`/`hanging` 숫자 입력 + 미리보기.
- 기존 툴바 패턴(`DropdownMenu`, 제목 강조색 팝오버)을 그대로 따른다.
