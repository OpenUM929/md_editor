   Update 계좌
   Set 잔액=잔액-5000
   Where 계좌번호=100;

   Update 계좌
   Set 잔액 = 잔액+5000
   Where 계좌번호=200;
변경 전

100 : 5000원
200 : 5000원
변경 후
 100 : 0원
200 : 10000원
