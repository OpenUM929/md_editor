# 보고서 표준 양식 가이드
> 원본 파일(`1.pdf`, 「ICT설비관리시스템」 구축 완료보고)을 실측(폰트 크기·좌표·RGB 색상·선굵기·행간)하여 추출한 표준 지침입니다.

---

## 1. 페이지 설정

| 항목 | 값 |
|---|---|
| 용지 | A4 (210 × 297mm / 595.32 × 841.92pt) |
| 왼쪽 여백 | 약 21mm (59.5pt) |
| 오른쪽 여백 | 약 21mm (59.9pt) |
| 위쪽 여백 | 약 21mm (59.5pt, 제목 박스 상단 기준) |
| 아래쪽 여백 | 약 21mm (59.7pt, 본문이 꽉 찬 페이지 기준 실측) |
| 본문 좌측 기준선 | x ≈ 56.6pt (섹션 제목 시작 위치) |
| 이미지/스크린샷 삽입 폭 | x = 56.6 ~ 550.1pt (텍스트 여백보다 좌우 각 약 3pt씩 더 채워 배치) |

> 상하좌우 여백이 모두 **대칭 21mm**로 통일된 구조입니다.

### 1-1. 박스/셀 내부 여백 (padding)

| 요소 | 전체 높이 | 텍스트 크기 | 내부 여백(상/하) |
|---|---|---|---|
| 제목 박스 | 44.5pt | 22pt | 각 11.3pt (수직 중앙정렬) |
| 붙임 배지 박스 | 32pt | 18pt | 각 7pt (수직 중앙정렬) |
| 표 셀 | 25.6pt | 11pt | 위 8.2pt / 아래 6.4pt (수직 중앙정렬) |

### 1-2. 참고: 시스템 각인(워터마크) — 표준 양식에는 미포함
원본 PDF의 각 페이지 우측 하단(페이지 끝에서 약 6mm/17.3pt 지점)에는 문서관리시스템이 자동으로 삽입하는 문서번호·타임스탬프 각인이 이미지 형태로 찍혀 있습니다. 이는 사용자가 작성하는 본문 여백과 무관한 **시스템 자동 스탬프**이므로 표준 양식(및 아래 템플릿 스크립트)에는 반영하지 않았습니다. 실제 사내 시스템에 연동해 출력할 경우에만 별도로 추가하면 됩니다.

## 2. 제목 (표지형 타이틀)

| 항목 | 값 |
|---|---|
| 텍스트 형식 | 낫표 사용 — `「제목」 + 구축 완료보고` |
| 글자 크기 | **22pt**, 굵게 |
| 정렬 | 박스 안에서 가로 중앙 정렬 |
| 박스 배경색 | 연회색 `#F2F2F2` (RGB 242,242,242) |
| 박스 테두리 | 이중선 — 위/왼쪽 얇은선(0.6~0.7pt) + 아래/오른쪽 굵은선(1.4pt) → 입체(엠보싱) 느낌 |
| 박스 크기 | 가로 약 168mm(475.9pt) × 세로 약 15.7mm(44.5pt), 페이지 가로 중앙 배치 |

## 3. 담당자 정보 (Byline)

| 항목 | 값 |
|---|---|
| 글자 크기 | 12pt, 일반 |
| 정렬 | 오른쪽 정렬, 제목 박스 바로 아래 |
| 형식 | `부서 직급 이름(☎내선번호)` |

## 4. 섹션 제목 (1. 2. 3. 4. …)

| 항목 | 값 |
|---|---|
| 글자 크기 | **17pt**, 굵게 |
| 정렬 | 왼쪽 정렬 (본문 좌측 기준선) |
| 형식 | `N. 제목` |
| 섹션 앞 여백 | 이전 내용과 약 35~45pt 간격 (문단 간격보다 넉넉하게) |

## 5. 본문 – 개조식 불릿 체계

| 기호 | 의미 | 글자 크기 | 들여쓰기(좌측 기준선 대비) |
|---|---|---|---|
| `□` | 1단계 핵심 항목 | 15pt | 약 46pt (텍스트 시작 x≈106) |
| `○` | 2단계 하위 항목 | 13~15pt | 약 30pt (텍스트 시작 x≈86~90) |
| `※` | 참고/근거 각주 | 15pt | 약 18pt (텍스트 시작 x≈75) |
| **볼드 강조** | 핵심 수치·용어 | 본문과 동일 크기, 굵게 | - |

- 각 기호 뒤에는 탭 정렬(고정폭 들여쓰기) 사용, 자간은 본문과 동일.
- 표 제목(메인화면/H·W 관리 등)처럼 이미지 위 캡션은 13pt 별도 스타일.

## 6. 줄간격 / 문단간격

| 항목 | 값 |
|---|---|
| 본문 줄간격 | 약 27pt (15pt 폰트 기준 약 180%) |
| 같은 섹션 내 문단 간격 | 27pt (줄간격과 동일, 별도 여백 없음) |
| 섹션 헤더 앞 간격 | 35~45pt |

## 7. 붙임(첨부) 배지 헤더

표지 이후 별지(붙임1, 붙임2…) 상단에 쓰는 라벨 스타일입니다.

| 항목 | 값 |
|---|---|
| 배지 배경색 | 남색 `#1B1760` (RGB 27,23,96) |
| 배지 글자 | 흰색, 굵게, 18pt (`붙임1`, `붙임2`) |
| 배지 크기 | 가로 약 22mm(63.4pt) × 세로 약 11mm(32pt) |
| 배지 옆 제목 | 검정, 굵게, 18pt, 배지와 동일 세로 정렬 |

## 8. 표(테이블) 스타일

| 항목 | 값 |
|---|---|
| 헤더/강조 셀 배경 | 연회색 `#F2F2F2` |
| 테두리 | 검정, 얇은선 0.5~0.7pt (바깥 테두리는 약간 더 굵게) |
| 데이터 셀 글자 크기 | 표 성격에 따라 10~11pt(수치 테이블), 15pt(간단 요약 테이블) |
| 정렬 | 텍스트는 좌측/중앙, 숫자는 중앙 또는 우측 |

## 9. 색상 팔레트

| 용도 | 색상 | HEX |
|---|---|---|
| 강조(배지) | 남색 | `#1B1760` |
| 배경(제목박스/표헤더) | 연회색 | `#F2F2F2` |
| 본문/제목 텍스트 | 검정 | `#000000` |
| 테두리/선 | 검정 | `#000000` |

> 본문 텍스트는 전 구간 검정색만 사용 — 색상 강조 없이 크기·굵기·배경박스로만 위계를 구분하는 **공문서형 흑백 스타일**입니다.

## 10. 폰트

- 원본은 임베디드 서브셋 폰트(CID TrueType, 실제 폰트명 확인 불가)를 사용했으나, 자간·형태상 **맑은 고딕(Malgun Gothic)류 산세리프 계열**로 추정됩니다.
- 대체 시 `맑은 고딕` 또는 `Noto Sans KR`을 권장합니다.

## 11. 문서 구조 템플릿

```
「제목」 (22pt, 회색박스)
                                   부서 직급 이름(☎번호) (12pt, 우측정렬)

1. 구축배경 (17pt bold)
  □ 핵심 내용 (15pt)
    ※ 관련 근거 (15pt, 들여쓰기)

2. 개발내용 (17pt bold)
  □ 항목: 값 (15pt)
  □ 항목: 값
  [스크린샷 2단 배치 - 좌: 설명, 우: 설명]

3. 기대효과 (17pt bold)
  □ (정성적) 강조내용 (15pt, 괄호부분 bold)
  □ (정량적) 강조내용

4. 향후계획 (17pt bold)
  □ 계획 내용

--- 페이지 나눔 ---

[붙임1 배지] 제목 (18pt)
1. 소제목 : 설명 (15pt)
   [스크린샷]
```
