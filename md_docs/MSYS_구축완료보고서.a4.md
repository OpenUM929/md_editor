## 6. 시스템 구성 및 책임 경계

- MSYS는 데이터 수집을 **실행하는 시스템이 아니라, 수집 결과를 관측·관리하는 시스템**입니다.

수집 작업은 데이터 수집 파트가 Airflow로 수행하며, 그 진행 상태를 공유 데이터베이스에 기록합니다.
MSYS는 이 기록을 읽어 모니터링 정보로 가공·표출하고, 수집에 필요한 기준정보와 API키 수명을 관리합니다.

![시스템 책임 경계 개념도](/manual_images/fig1-boundary.png)

- **책임 분계** — 데이터베이스가 두 파트의 인계 지점입니다.

| 구분 | 데이터 수집 파트 | 모니터링 파트 (MSYS) |
|------|----------------|---------------------|
| 수집 실행·재시도 | ● 담당 | ○ 관여 없음 |
| 수집 상태 기록 | ● 담당 | ○ 관여 없음 |
| 현황 집계·표출 | ○ | ● 담당 |
| 장애 분석·통계 | ○ | ● 담당 |
| 기준정보·권한·API키 관리 | ○ | ● 담당 |

> 수집 실패 자체의 원인 조치는 수집 파트 소관이며, MSYS는 **실패 사실을 신속히 드러내는 것**까지를 책임 범위로 합니다.

## 7. 수집 상태의 기록·표출 흐름

- 수집 1회의 생명주기가 **화면에 도달하기까지의 경로**입니다.

![수집 1회의 생명주기](/manual_images/fig2-lifecycle.png)

- **단계별 설명**

| 단계 | 주체 | 동작 | 근거 |
|:--:|------|------|------|
| ① | Airflow | 수집 시작 시 `tb_con_hist` INSERT — `start_dt`·`execution_dt`·`status` 기록 | `DDL/tb_con_hist.sql` |
| ② | **DB 트리거** | INSERT를 감지해 변경 전체를 `jsonb`로 이벤트 로그에 적재 | `trg_log_con_hist_changes` |
| ③ | Airflow | 수집 완료 시 **동일 행을 UPDATE** — `end_dt`·최종 `status` 기록 | `DDL/tb_con_hist.sql` |
| ④ | **DB 트리거** | UPDATE도 동일하게 이벤트 로그에 적재 | `AFTER INSERT OR UPDATE` |
| ⑤ | Airflow | 장애 시 `tb_con_trbl_hist`에 장애코드·재시도 횟수 기록<br>`tb_con_hist.trbl_hist_no`로 연결 | `DDL/tb_con_trbl_hist.sql` |
| ⑥ | MSYS | 조회·집계하여 각 화면에 표출 | `dao/con_hist_dao.py` |

> **설계상 요점** — 이력 테이블은 수집 1회당 **한 행이 INSERT 후 UPDATE로 갱신**되므로 최신 상태만 남습니다.
> 시작·완료의 시점별 경과는 DB 트리거가 자동 생성하는 이벤트 로그에 보존되며, MSYS는 애플리케이션 수정 없이 이 이력을 확보합니다.

## 8. 화면-데이터 연계

- 수집 상태값이 화면 지표로 전환되는 규칙입니다.

![수집 상태값의 화면 지표 전환](/manual_images/fig3-mapping.png)

| 항목 | 내용 |
|------|------|
| 상태 코드 관리 | `tb_sts_cd_mst`에 등록된 코드를 `status_code_service`가 조회하여 적용<br>운영 중 코드 추가 시 화면 로직 수정 불필요 |
| 시간 기준 | 저장은 `timestamp with time zone`, 집계는 **한국시간(KST) 일자 기준**으로 변환 후 수행 |
| 장애코드 분석 | `tb_con_hist.status`가 성공 코드가 아닌 건을 코드별로 집계 |

- **화면별 참조 데이터**

| 화면 | 참조 | 표출 내용 |
|------|------|----------|
| 대시보드 | `tb_con_hist` | Job별 수집현황 집계, 이벤트 로그, 데이터 보유기간 |
| 실시간 현황 | `tb_con_hist` | Job별 카드 형식 상태 |
| 차트분석 | `tb_con_hist` | 성공률 추이, 장애코드별 비율 |
| 데이터분석 | `tb_con_hist` | 기간별 추이, 동적차트, 원본 로그 |
| 수집일정 | `tb_con_hist` + `tb_data_clt_schd_sett` | 일정별 수집 결과, 그룹 메모 |
